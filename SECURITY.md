---

## Reporting a Vulnerability

The **Deepfake Forensics Platform** is designed for forensic verification and security applications. We treat security vulnerabilities with the highest priority.

### Disclosure Process
1. **Do NOT open a public GitHub issue** for undisclosed security vulnerabilities.
2. Please report vulnerabilities directly via GitHub Private Vulnerability Reporting or by contacting the repository maintainers.
3. Provide a detailed summary including:
   - Vulnerability classification (e.g., Remote Code Execution, Denial of Service via malicious container atom, Buffer Overflow in video decoding).
   - Exact steps or minimal reproducible media sample to reproduce the issue.
   - Potential impact on forensic systems.

### Response Timeline
- **Initial Acknowledgment**: Within 48 hours of receipt.
- **Triage & Status Assessment**: Within 5 business days.
- **Patch Release & Public Advisory**: Coordinated with the reporting party once a remediating fix has been verified.
