## 1. Executive Summary & Acoustic Anti-Spoofing Theory

`voice_model.py` implements a specialized, ultra-lightweight 2D convolutional neural network designed to detect synthetic speech generated by neural vocoders, voice cloning systems, and Text-to-Speech (TTS) models (e.g. ElevenLabs, Tortoise-TTS, VITS, RVC, So-VITS-SVC).

Natural human speech is produced through the physical acoustics of the human vocal tract (lungs, vocal folds, pharynx, oral and nasal cavities). Neural vocoders (such as HiFi-GAN, MelGAN, or WaveGlow) synthesize speech waveforms by inverting mel-spectrogram representations using transposed convolutions. Due to fixed upsampling strides and time-frequency loss objectives, synthetic voices exhibit distinct, indelible anomalies:
1. **Periodic Spectral Modulation**: Transpose convolutions induce checkerboard-like harmonic artifacts in the high-frequency mel bands.
2. **Phase Inconsistency Across Frames**: Neural vocoders struggle to maintain continuous acoustic phase coherence across adjacent pitch periods.
3. **Spectral Power Starvation**: Extreme high frequencies ($>6\text{ kHz}$) often display unnaturally sharp cutoffs or synthetic noise floors.

## 2. Depthwise Separable Convolutions: `DepthwiseSeparableConv`

To achieve sub-millisecond inference on edge servers and CPU deployments, the model implements **Depthwise Separable Convolutions** (Howard et al., *MobileNets*, arXiv:1704.04861):

```python
class DepthwiseSeparableConv(nn.Module):
    def __init__(self, in_channels, out_channels, stride=1):
        super().__init__()
        self.depthwise = nn.Conv2d(in_channels, in_channels, kernel_size=3, padding=1, stride=stride, groups=in_channels, bias=False)
        self.pointwise = nn.Conv2d(in_channels, out_channels, kernel_size=1, bias=False)
        self.bn = nn.BatchNorm2d(out_channels)
        self.relu = nn.ReLU(inplace=True)

    def forward(self, x):
        x = self.depthwise(x)
        x = self.pointwise(x)
        x = self.bn(x)
        return self.relu(x)
```

### 2.1 Mathematical Factorization
A standard 2D convolution filters and combines input channels simultaneously. Depthwise separable convolution splits this into two independent operations:

1. **Depthwise Spatial Convolution**:
   Applies a single $3 \times 3$ spatial filter per input channel independently (`groups = in_channels`):
   $$\mathbf{y}_{\text{depthwise}}^c(i, j) = \sum_{m=-1}^1 \sum_{n=-1}^1 \mathbf{K}_{\text{depthwise}}^c(m, n) \cdot \mathbf{x}^c(i \cdot s + m, j \cdot s + n)$$
2. **Pointwise Channel Projection**:
   Applies a $1 \times 1$ convolution to compute linear combinations across channels:
   $$\mathbf{y}^k(i, j) = \sum_{c=1}^{C_{\text{in}}} \mathbf{K}_{\text{pointwise}}^{c, k} \cdot \mathbf{y}_{\text{depthwise}}^c(i, j)$$
3. **Batch Normalization & Non-Linear Activation**:
   $$\mathbf{y}_{\text{out}} = \text{ReLU}\left( \text{BatchNorm}(\mathbf{y}) \right)$$

### 2.2 Computational Complexity Comparison:
For input feature map $D_F \times D_F$, kernel size $D_K = 3$, input channels $C_{\text{in}}$, and output channels $C_{\text{out}}$:
* Standard Convolution Cost:
  $$\text{FLOPs}_{\text{std}} = D_K^2 \cdot C_{\text{in}} \cdot C_{\text{out}} \cdot D_F^2 = 9 \cdot C_{\text{in}} \cdot C_{\text{out}} \cdot D_F^2$$
* Depthwise Separable Convolution Cost:
  $$\text{FLOPs}_{\text{sep}} = D_K^2 \cdot C_{\text{in}} \cdot D_F^2 + C_{\text{in}} \cdot C_{\text{out}} \cdot D_F^2 = C_{\text{in}} \cdot D_F^2 \cdot (9 + C_{\text{out}})$$
* **Efficiency Ratio**:
  $$\frac{\text{FLOPs}_{\text{sep}}}{\text{FLOPs}_{\text{std}}} = \frac{1}{C_{\text{out}}} + \frac{1}{9} \approx \frac{1}{9} \quad (\mathbf{\sim 88.9\% \text{ Reduction in Computational Overhead}})$$

## 4. Model Loading & Inference Pipeline

### 4.1 Weight Discovery & Safe Deserialization
```python
def load_weights(self, path=None):
    if path is None:
        path = os.path.join(os.path.dirname(os.path.dirname(__file__)), "weights", "voice_spoofing.pth")
    
    device = torch.device("cuda" if torch.cuda.is_available() else "cpu")
    self.to(device)
    
    if os.path.exists(path):
        self.load_state_dict(torch.load(path, map_location=device, weights_only=True))
    else:
        print(f"Warning: Synthetic voice weights not found at {path}.")
```
* **Security**: Enforces `weights_only=True`, preventing arbitrary Python pickle execution vulnerabilities when loading model checkpoints.
* **Automatic Device Allocation**: Moves parameters to CUDA if available, else falls back to CPU execution.

### 4.2 Inference Execution: `predict()`
```python
def predict(self, mel_spectrogram):
    device = next(self.parameters()).device
    self.eval()
    
    with torch.no_grad():
        tensor = torch.FloatTensor(mel_spectrogram).unsqueeze(0).unsqueeze(0).to(device)
        prob = self(tensor).item()
        
    return prob
```
* Ingests a raw 2D NumPy array of shape $(N_{\text{mels}}, T)$.
* Expands batch and channel dimensions to shape $(1, 1, N_{\text{mels}}, T)$.
* Evaluates within `torch.no_grad()` and returns a Python `float` representing $P(\text{Spoofed})$.
